# Installation

Follow these steps to integrate the Halo SDK UI into your Android project.

## 1. Configure Credentials

To access the SDK, you will receive an AWS access key and secret key upon registration on the developer portal. These are sensitive credentials and should **not** be committed to source control.

Add these to your `local.properties` file:

```properties
aws.accesskey=< PROVIDED IN EMAIL >
aws.secretkey=< PROVIDED IN EMAIL >
```

## 2. Configure Repositories

In your `settings.gradle.kts` (or `settings.gradle`), load the credentials and configure the S3-hosted Maven repository.

<Tabs>
<TabItem value="kotlin" label="Kotlin DSL">

```kotlin
import java.util.Properties

val localProperties = Properties().apply {
    val localPropertiesFile = rootDir.resolve("local.properties")
    if (localPropertiesFile.exists()) {
        localPropertiesFile.inputStream().use { load(it) }
    }
}

dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
        // Repository where Halo SDK UI is hosted
        maven {
            name = "releases"
            url = uri("s3://synthesis-halo-artifacts/releases")
            credentials(AwsCredentials::class) {
                accessKey = localProperties.getProperty("aws.accesskey")
                secretKey = localProperties.getProperty("aws.secretkey")
            }
        }
    }
}
```

</TabItem>
</Tabs>

## 3. Add Dependency

Add the following to your module's `build.gradle.kts`:

```kotlin
dependencies {
    implementation("za.co.synthesis.halo:sdk_ui:0.0.1")
}
```

:::tip
Replace `0.0.1` with the latest version available.
:::

## 🛡️ Permissions

The SDK requires several permissions for NFC, location (for compliance), and network access. These are automatically merged into your app's manifest.

| Permission | Purpose |
|------------|---------|
| `android.permission.INTERNET` | Network communication with Halo backend |
| `android.permission.NFC` | Reading payment cards via NFC |
| `android.permission.ACCESS_FINE_LOCATION` | Required for payment compliance (location verification) |
| `android.permission.ACCESS_COARSE_LOCATION` | Alternative location permission for compliance |

:::warning
You should use the built-in helper or standard Android APIs to request these permissions at runtime before launching a transaction.
:::
