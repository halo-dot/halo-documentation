# Push to Terminal Integration Guide

Integration with the Halo backend to send payment requests directly to a registered device via push notification.

## 1. Architecture

The Push to Terminal flow allows a merchant system to push a payment request to a specific device without the customer needing to scan a QR code. The process is as follows:

1. Merchant system calls `POST /devices` to register a device with its Firebase token.
2. Merchant system calls `GET /devices` to retrieve the list of registered devices.
3. Merchant system selects the target device and calls `POST /devices/push` with the payment details.
4. The Halo backend sends a Firebase push notification to the selected device.
5. The Halo.Go app on the device receives the notification, displays the payment request, and initiates a card read.

If the push notification fails (device offline, invalid token), the backend automatically returns a fallback applink URL with a QR code that the customer can scan instead.

## 2. Device Management API

### 2.1 List Devices

Retrieve all devices registered by the authenticated user.

<mark style={{color:'green'}}>`GET`</mark> `https://kernelserver.{env}.haloplus.io/devices`

<span/>

**Path Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| env<mark style={{color:'red'}}>\*</mark> | String | The backend environment \[dev, qa, prod] |

**Headers**

| Name | Type | Description |
| ---- | ---- | ----------- |
| x-api-key<mark style={{color:'red'}}>\*</mark> | String | The API Key retrieved from the Merchant Portal (JWT can be used instead) |
| Authorization<mark style={{color:'red'}}>\*</mark> | String | The JWT retrieved from logging in. (API Key can be used instead) |

### 2.2 Register Device

Register a device with its Firebase token and an optional friendly name. If the device already exists (same deviceInstallationId + user), it will be updated.

<mark style={{color:'blue'}}>`POST`</mark> `https://kernelserver.{env}.haloplus.io/devices`

<span/>

**Path Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| env<mark style={{color:'red'}}>\*</mark> | String | The backend environment \[dev, qa, prod] |

**Headers**

| Name | Type | Description |
| ---- | ---- | ----------- |
| Content-Type<mark style={{color:'red'}}>\*</mark> | String | Content Type of the Request: application/json |
| x-api-key<mark style={{color:'red'}}>\*</mark> | String | The API Key retrieved from the Merchant Portal (JWT can be used instead) |
| Authorization<mark style={{color:'red'}}>\*</mark> | String | The JWT retrieved from logging in. (API Key can be used instead) |

**Request Body**

| Name | Type | Description |
| ---- | ---- | ----------- |
| deviceInstallationId<mark style={{color:'red'}}>\*</mark> | String | The device installation ID from the Halo.Go app |
| firebaseToken | String | Firebase Cloud Messaging token for push notifications |
| friendlyName | String | Human-readable name for the device (max 128 characters) |

<span/>

## 3. Push to Device API

### 3.1 Send Payment Request

Push a payment request to a specific device via Firebase push notification.

<mark style={{color:'blue'}}>`POST`</mark> `https://kernelserver.{env}.haloplus.io/devices/push`

<span/>

**Path Parameters**

| Name | Type | Description |
| ---- | ---- | ----------- |
| env<mark style={{color:'red'}}>\*</mark> | String | The backend environment \[dev, qa, prod] |

**Headers**

| Name | Type | Description |
| ---- | ---- | ----------- |
| Content-Type<mark style={{color:'red'}}>\*</mark> | String | Content Type of the Request: application/json |
| x-api-key<mark style={{color:'red'}}>\*</mark> | String | The API Key retrieved from the Merchant Portal (JWT can be used instead) |
| Authorization<mark style={{color:'red'}}>\*</mark> | String | The JWT retrieved from logging in. (API Key can be used instead) |

**Request Body**

| Name | Type | Description |
| ---- | ---- | ----------- |
| deviceId<mark style={{color:'red'}}>\*</mark> | String | The device ID (UUID from `GET /devices`) |
| amount<mark style={{color:'red'}}>\*</mark> | Number | Payment amount (minimum 0.01) |
| currency<mark style={{color:'red'}}>\*</mark> | String | 3-letter ISO currency code (e.g. ZAR, USD) |
| merchantReference<mark style={{color:'red'}}>\*</mark> | String | Unique reference for this payment |

<span/>

## 4. Integration Example

<Tabs>
  <TabItem value="node" label="Node.js">

```javascript
const axios = require('axios');

const BASE_URL = 'https://kernelserver.prod.haloplus.io';
const API_KEY = 'your-api-key';
const headers = { 'x-api-key': API_KEY, 'Content-Type': 'application/json' };

// Step 1: Register a device
await axios.post(`${BASE_URL}/devices`, {
  deviceInstallationId: 'AA1A109DF2C4208F3ABBC062A343464C',
  firebaseToken: 'fcm-token-from-device',
  friendlyName: 'Front Counter'
}, { headers });

// Step 2: List devices
const devices = await axios.get(`${BASE_URL}/devices`, {
  headers: { 'x-api-key': API_KEY }
});

// Step 3: Push payment to device
const device = devices.data.find(d => d.friendlyName === 'Front Counter');
const push = await axios.post(`${BASE_URL}/devices/push`, {
  deviceId: device.id,
  amount: 50.00,
  currency: 'ZAR',
  merchantReference: 'ORDER-001'
}, { headers });

if (push.data.status === 'sent') {
  console.log('Push sent, transaction:', push.data.transactionId);
} else {
  console.log('Fallback -- display QR code to customer');
}
```
